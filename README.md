# Iris Dataset Analysis

## Overview

This project performs basic analysis on the Iris dataset using Python and Pandas.

## Features

* Load Iris dataset
* Display first 5 rows
* Show dataset shape
* Display column names
* Generate statistical summary
* Check missing values

## Technologies Used

* Python
* Pandas
* Scikit-learn

## File Included

* `iris.py` — Python script for dataset analysis

## How to Run

1. Install required libraries:

   ```bash
   pip install pandas scikit-learn
   ```

2. Run the Python file:

   ```bash
   python iris.py
   ```

## Output

The program displays:

* Dataset preview
* Shape of dataset
* Column details
* Statistical information
* Missing value report
